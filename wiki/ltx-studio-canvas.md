# LTX Studio Canvas

Canvas is a collaborative infinite workspace embedded inside [[ltx-studio]], released in late April 2026. It serves as the primary visual ideation layer for creative teams before committing to full production.

## Overview

- **Type:** Collaborative infinite canvas / visual moodboard
- **Released:** Late April 2026
- **Availability:** All [[ltx-studio]] plans (Free and above)
- **URL:** Accessible from within https://app.ltx.studio

## Key Capabilities

### Real-Time and Async Collaboration

Teams can generate, iterate, and align on concepts either in real time or asynchronously without switching tools. Multiple collaborators can work on the same canvas simultaneously.

### Visual Ideation

- Combine image and video moodboards on a shared infinite canvas
- Drag, arrange, and annotate visual references freely
- Generate video clips using any LTX Studio model directly from within the canvas

### End-to-End Production Flow

Users can move seamlessly from concept to production without leaving the platform:

1. **Concept**: Build moodboards, drop in reference images and videos
2. **Ideation**: Generate video using multiple models for comparison
3. **Audio**: Add and preview audio alongside video
4. **Edit**: Move to the timeline editor for final cut
5. **Export**: Deliver final output without switching tools

## Integration with Other LTX Studio Features

- **[[ltx-studio-flows|Flows]]**: Canvas serves as the ideation phase before a Flow is configured for batch production
- **Gen Space**: Video generation from the canvas uses the same model picker as Gen Space (LTX, Veo 3.1, Seedance 2.0, etc.)
- **Brand Kit (Enterprise)**: Brand assets can be pinned to the canvas for reference throughout ideation

## Use Cases

- Pre-production storyboard alignment across remote teams
- Concept exploration before committing model credits to full generation
- Client presentation boards with in-context video previews
- Multi-brand campaign planning (with Brand Kit integration)
