# Runway: Rapid-Fire September 2026 Feature and Integration Blitz

**Source:** https://runway.com/changelog
**Date:** 2026-09-04 through 2026-09-23 (multiple entries)
**Retrieved:** 2026-09-28

## Content

Runway shipped an unusually dense run of incremental updates through September 2026, continuing its pivot toward being a multi-model "aggregator/router" platform rather than a single-model competitor. No new flagship Runway-trained video model shipped this window (Gen-4.5 remains the latest, Dec 2025); nearly all movement was integrations, editorial-tool plugins, and MCP (agent) ecosystem expansion.

Dated entries within the window:
- **Sep 4** — Introducing Team Plan: new self-serve plan for small teams; each seat adds 6,900 credits/month to a shared pool, up to 9 people, 1TB shared storage, shared agent skills.
- **Sep 8** — Runway Adobe Plugins: Runway now runs as a panel inside Adobe Premiere Pro and After Effects — generate with Runway's full model lineup, restyle existing timeline footage with Aleph 2, place results directly into a comp/sequence. Free plugin download for macOS/Windows, works with existing paid plans/credits.
- **Sep 10** — Agent Brand Kits: the Runway Agent can now create/edit Brand Kits conversationally.
- **Sep 11** — Ruby (Runway's native HDR/color-grading model) now preserves the alpha channel of source video with automatic detection.
- **Sep 12** — `/v1/video_to_hdr` API's `hdr_exr_acescg_sequence` output is now built from the source plate, improving ACES SDR/HDR consistency.
- **Sep 15** — Agent in Asset Comments: @-mention Agent directly in comments on any asset page.
- **Sep 17** — Enhance Frame Rate (Max+ plans): convert any video (Runway-made or not) to 24/25/30/48/50/59.94/60/120 fps, up to 4K and 5 minutes. Same day: Runway MCP launched as a plugin for Grok Bot (sign in with Runway account to generate from a Grok Bot chat).
- **Sep 18** — Kling models added to Runway MCP: Kling O3 4K, Kling 3.0 Standard, Kling O3 Standard, Kling 3.0 Motion Control.
- **Sep 22** — Brand Kits in Runway MCP: agents can now find and use (read-only) Brand Kit assets as references.
- **Sep 23** — Two entries: (1) DaVinci Resolve Plugin — Runway now available directly inside DaVinci Resolve; (2) Runway MCP listed on Cursor's Marketplace, bringing Runway's generative tools into Cursor coding workflows.

## Strategic context
This continues the trajectory noted in the 2026-08-24 log entry: Runway's Media Router (launched Jul 23) is now backed by a rapidly expanding MCP/agent integration surface (Grok Bot, Cursor, Kling models) plus deep editorial-tool plugins (Premiere, After Effects, DaVinci Resolve). Runway is positioning itself as the integration/orchestration layer across creative tools and third-party models (including competitors like Kling) rather than competing purely on its own model quality. Runway is hosting an "AI Summit" in San Francisco on 2026-09-30, just after this window, with speakers from DeepMind, NVIDIA, and Physical Intelligence.
