# Runway API — Gemini Omni Flash, Agent Skills, Seedream 5.0 Lite, Veo negativePrompt

**Source:** https://docs.dev.runwayml.com/api-details/api_changelog/ ; https://runwayml.com/changelog
**Date:** 2026-07-01 to 2026-07-15 (approximate, per Runway changelog)
**Retrieved:** 2026-07-21

## Content

Runway made several incremental API/product additions during the research window (no new flagship Gen-4.x model this week, but notable third-party model integrations and workflow features):

- **July 1, 2026** — Gemini Omni Flash became available via the Runway API.
- **~July 1, 2026** — Nano Banana 2 Lite added to Runway for fast image generation.
- **July 2, 2026** — "Agent Skills" introduced: lets users build ad campaigns, create commercials, localize ads, and more via a simple command/prompt interface (marketing-automation direction, following the June 25 "Agent 2.0" campaign-creation launch).
- **Mid-July 2026** — Runway API added optional `negativePrompt` support for Veo3, Veo3.1, and Veo3.1-fast text-to-video and image-to-video requests.
- **Mid-July 2026** — Seedream 5.0 Lite (ByteDance's image model) became available via the Runway API, alongside existing Seedance 2.0/Seedream integrations.

**Context:** Runway continues its strategy (also seen in June: Studio Trim, Agent 2.0, Seedance 2.0/Mini API) of being a model-agnostic aggregator — bundling its own Gen-4/Gen-4.5/Aleph models with third-party models (Veo, Kling, Seedance, Seedream, FLUX) under one subscription/API, rather than only shipping its own new foundation model.
