# LTX Studio: Flows Feature Launch (May 7, 2026)

**Source:** https://ltx.studio/release-notes
**Date:** 2026-05-07
**Retrieved:** 2026-05-25

## Content

Lightricks launched "Flows" in LTX Studio on May 7, 2026 — a visual, node-based system for building and automating video workflows. This was announced on X/Twitter by @LTXStudio (tweet: https://x.com/LTXStudio/status/1919751150888239374).

### Feature Description

Flows is a node-based workflow builder that allows users to:
- Connect prompt nodes, image nodes, video nodes, and upscaling nodes
- Run entire pipelines with one click
- Build workflows once and reuse them at any scale
- Automate multi-step video production pipelines

The feature is accessible via the LTX Model section (not just LTX Studio platform), indicating it ties into the open model ecosystem.

### Strategic Significance

Flows represents a shift toward LTX Studio as a **workflow automation platform** rather than just a generation tool. Key implications:
- Enables production-scale video pipelines without code
- Brings ComfyUI-style node graphs to a polished UI
- Targets professional studios and agencies who need repeatable workflows
- Complements the Canvas feature (launched April 27) for collaborative ideation
